# Legacy portal migration map

The old portal used booking and provider-assignment language. The current CRM uses a simpler internal lead workflow.

## Current flow

1. Receive lead from website, agent, call, WhatsApp, or admin.
2. Verify customer and requirement details.
3. Categorize the lead.
4. Approve, reject, complete, or close the lead.
5. Track follow-ups and communications on separate pages.

## Terminology mapping

| Legacy portal | Current CRM |
| --- | --- |
| Booking | Lead / requirement |
| Customer booking form | Lead intake form |
| Vet / professional assignment | Removed from CRM workflow |
| Booking status | Lead verification/approval status |
| Search bookings | Search leads |
| Follow up | Follow-up task |
| Provider dashboard unlock | Not active in current version |

The provider module is now an internal directory and onboarding record only. Lead approval is the final CRM action; there is no provider assignment or distribution step.
